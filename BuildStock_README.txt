This is a browser-based HTML/CSS/JavaScript prototype for classroom use.

Important:
- Data is stored in each browser using localStorage.
- GitHub Pages can host the app, but it does not create a shared database.
- The fixed version uses explicit DOM element lookups in all transaction forms, preventing the Save/Record buttons from failing because form fields were referenced as undeclared variables.

Main features:
- Dashboard
- Materials Master
- Supplier Directory
- Delivery Transactions
- Issuance Transactions
- Returns Transactions
- Reports & Analytics
- Audit Trail
- Login
- CSV export

To publish with GitHub Pages, upload index.html and this README to a public repository, then enable Settings > Pages > Deploy from branch > main > /(root).
